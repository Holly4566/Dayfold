# 日序 · MVP

## 必须实现

1. 默认进入全局“每日”。
2. 时间计划四个独立清单：每日、每周、每月、近期。
3. 八个默认分类；点击分类默认进入该分类的“每日”。
4. 分类内部可切换四个时间周期。
5. 事项新增、编辑、完成/取消完成、删除。
6. 事项字段：标题（必填）、日期（必填）、时间（可选）。
7. 未完成事项按日期、时间升序；同日无时间事项排在有时间事项之后。
8. 已完成事项移到底部并默认折叠；过期未完成日期低调标红。
9. 分类可新增、重命名、上移、下移、隐藏与恢复。
10. JSON 导出/导入；导入校验后替换全部数据，并先生成安全备份。
11. 响应式桌面/手机布局；手机使用汉堡菜单，不使用底部导航。
12. PWA 清单、Service Worker 与图标，可安装并离线打开。

## 暂不实现

- 账号、云端同步、多人协作。
- 通知、重复事项、备注、优先级、附件。
- 搜索、日历、统计、进度条。

## 验收标准

- 刷新或重新打开时回到全局“每日”。
- 刷新后本机数据仍保留。
- 核心交互在桌面 Edge 和 Android Chrome 尺寸下可用。
- 无横向溢出、无明显布局跳动、无控制台错误。
